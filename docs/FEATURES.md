# Aniimo Companion Workspace — feature reference

A companion workspace workspace for Aniimo, built around collection notes and exploration plans, with session profiles kept in a separate reference area.

| Section | Description |
|---|---|
| Collection notes | A dedicated section for collection notes and the configuration details associated with that area. |
| Exploration plans | A dedicated section for exploration plans and the configuration details associated with that area. |
| Session profiles | Related settings collected into named groups for a clearer configuration workflow. |

The project page follows the same section structure.
